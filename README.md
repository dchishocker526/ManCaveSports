# SportsHub - Live Sports Scores

A clean, fast, single-file live sports scores dashboard.

**Supported Leagues:**
- NFL, College Football (Top 25 + Big Ten)
- NBA, College Basketball
- MLB, NHL
- NASCAR (Cup, Xfinity, Truck), IndyCar, IMSA, F1

### Features
- Portrait-optimized layout (great for tablets)
- Live racing details (car numbers, gaps, last lap, flag status)
- Team logos and betting odds
- Auto-refresh every 60 seconds

### How to Use
Just open `index.html` in any browser.

---

Built with Tailwind CSS + ESPN Public API
